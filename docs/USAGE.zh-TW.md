# SmallStocks TW

台股，但小一點。沿用 Basesmall / SmalLoL 的桌面元件與安靜通知，讓少數自選股在角落持續監看。

目前為 **0.1.11 預覽版**，Windows 優先。名稱暫用 SmallStocks TW。

## 使用

免安裝版解壓縮後執行 `smallstocks-tw.exe`。需要 Windows WebView2；Windows 11 通常已有，缺少時需另裝 Microsoft WebView2 Runtime。執行檔尚未做程式碼簽章。

- 自選 → 管理自選：搜尋名稱／代號，或一次貼上多個代號（最多 30 檔）。
- 主窗：盤中、休市都維持一檔一行，預設純數字。盤中看即時價與漲跌幅；休市看最近正式收盤，共同日期只在下方顯示一次，較舊的個別標的才單獨標日期。三檔 small 預設約 360 × 148，單列高 22。
- 標題列「數字」可切換單行走勢：盤中看當天分鐘線，休市看近日最多 20 個交易日的收盤走勢。名稱、漲跌幅與列高不變，中間價格欄換成曲線；價格可從列提示或點開行情查看。按鈕依序切換數字、走勢、極簡；選擇會保存在本機，small 與灰階均可使用。
- 「外觀與設定 → 顯示內容」可選純數字／單行走勢／極簡；代號另有「顯示代號」開關，預設隱藏。名稱尚未取得時仍以代號辨識，搜尋與管理自選也會保留代號。
- 極簡只顯示方向與名稱：▲／▼ 為當日漲跌方向，small／灰階使用有厚度的正三角形，Terminal／記事本使用文字符號；— 平盤，○ 資料未確認或較舊。寬度足夠橫向並排，縮窄則換行，視窗高度自動跟著內容調整；不會改回你選定的寬度。
- small／灰階極簡會縮成約 30 px 高的細條，左側圓點可拖曳，右側「≡」回到數字、「⋯」開設定。Terminal／記事本保留各自外框，只縮減資料區。四種外觀都支援 hover 或鍵盤焦點看細節，點擊開完整行情。
- 點擊任一檔即可開啟該標的的「行情」詳情；回到「自選」會恢復緊湊尺寸。「＋」管理自選。收盤資料尚未公布時使用上一個可用交易日並標明日期。
- 行情：選自選標的與月份，查看每日開高低收、收盤走勢與成交量；可查詢 2000-01 至本月，實際可用範圍依標的上市時間與官方資料而定。
- 提醒：設定成交價或漲跌幅向上／向下跨越門檻，選擇每日一次或一次性、只記錄／細條／卡片／關閉。
- 外觀與設定：small 彩色、small 灰階、terminal 灰階、txt 灰階；通知色彩跟隨外觀，預設無聲。
- 「外觀與設定 → 視窗保持置頂」可決定主視窗是否蓋在其他視窗上方，預設開啟，切換後立即生效並保存，重開或切換四種外觀都沿用。關閉置頂、被遮住或隱藏到系統匣仍會繼續監看。事件通知與暫時的 hover 明細保留各自的浮窗行為。
- terminal：依平台使用 Windows Terminal／PowerShell 或 Mac 終端機／zsh 外觀，隱藏 small 導覽。從視窗內選單或 Windows `Ctrl+,`／Mac `⌘,` 開啟設定；可輸入 `help` 查看模式內指令。
- txt：Windows 使用記事本式分頁、選單與狀態列；Mac 使用 TextEdit 純文字文件窗，沒有 Windows 分頁與 CRLF 狀態列。兩者都可選取／複製報表與縮放。Windows 可切換狀態列、從齒輪或檔案選單回設定；Mac 從右上「⋯」開設定或操作。
- 「−」與關閉視窗只隱藏到系統匣，監看繼續。從系統匣可顯示或完整結束程式。
- Windows `Ctrl+Alt+S`／Mac `⌘⌥S` 隱藏全部視窗，並抑制後續通知；事件繼續記錄。從系統匣顯示主窗後恢復通知。快捷鍵若被其他程式占用可能無法註冊，設定會顯示原因。
- 外觀設定中的「暫停監看」才會停止抓取與事件判定。

一般模式直接由本機請求 TWSE MIS，不經開發者伺服器、不需帳號；預設 15 秒，錯誤時退避至最多 5 分鐘。只在台灣週一至週五 09:00–13:30 輪詢，啟動時會在其他時段取得一次參考資料。首版未載入官方休市日曆；休市日可能於上述時間輪詢，過期行情仍不觸發事件。

來源沒有有效成交價時顯示「—」，不使用委買賣價冒充成交價。來源超過 60 秒未更新、時間異常或跨交易日，不觸發通知。這個保守門檻可能略過低流動性標的或資料缺口期間的變化。缺值、重新連線、長時間中斷與重新啟動後，先重建基準，沒有追補漏掉的事件。

到價規則採「跨越」：首次看到的價格即使已高於門檻也不立刻提醒。例：設定向上跨過 1,000，需要先觀測到低於 1,000，再觀測到大於等於 1,000。當日已觸發記錄會持久化；修改同一條規則不清除當日記錄。事件本機最多保留 500 則。

每日歷史由本機直接取得 TWSE／TPEx 正式日資料，與 MIS 即時快照分開。首次讀取在背景依序取得、保存在本機；本月快取約一小時、其他月份約一天，同一月份重複查看會共用快取。最多快取 80 個「標的＋月份」。暫停監看會停止即時行情判定；仍可主動閱讀歷史資料。

每天 15:00 前不把當日列入已完成日資料，15:00 後也以來源實際公布為準。成交量依官方原始單位標示「股」「張」或「仟股」，不混為同一單位；指數沒有成交量的欄位會留空。日走勢每個點代表一個交易日收盤，價格未還原，除權息／分割等會造成跳動。這不是盤中重播，歷史資料不會觸發新通知。

## Terminal 與文字文件外觀

small 彩色與灰階沿用系列的圓角膠囊、緊湊字體與棋子厚度感。一般數字列呈現名稱／成交價或正式收盤／漲跌幅，hover 可看代號與資料時間，點擊開每日行情。單行走勢把價格欄換成 16 px 高的小折線，維持 22 px 列高；盤中顯示當天，休市顯示近日收盤。極簡改為有淺厚側面的正三角形＋名稱，hover 才顯示完整獨立明細，不把細條撐大。對照圖與介紹見專案 README。

極簡細節使用獨立且不取得焦點的浮窗，能顯示在細條外側，避免被主窗裁掉。內容包含代號、價格、漲跌幅、資料日期／時間及狀態；即使隱藏代號，細節仍可查看。Escape 或離開項目可關閉，隱藏程式時也會一起關閉。

這兩種模式只改變本體的顯示方式，沒有啟動實際 PowerShell 或 Windows 記事本。Terminal 模式的 `watch`、`list`、`rules`、`history`、`settings`、`small`、`pause`、`resume`、`hide`、`clear` 是本程式的顯示／監看操作，不會執行系統命令。記事本模式顯示自動更新的唯讀文字報表，不會開啟或修改其他文件。

資料更新時保留 Terminal 輸入列與記事本的選取、捲動位置。選取文字期間先保留該份文字，監看核心與事件判定仍繼續。兩種外觀的最小化／最大化／關閉按鈕連到本體視窗；關閉仍是隱藏到系統匣，完整結束請用系統匣選單。

## 單行分鐘線

選擇走勢模式且在一般交易時段時，本體會按需取得 Yahoo Finance 當天的一分鐘取樣，用來補齊開啟程式前來源有提供的部分，約每分鐘更新。分鐘線可能延遲，與 MIS 數字／規則判定分開；不拼接兩個來源，也不從圖線觸發通知。線段保留缺點與時間間隔，資料日期不同不冒充今天，尚無兩個有效點時顯示「待資料」。

櫃買指數目前無法從該來源補齊當天分鐘線；來源失敗時也可能使用本機開啟後取得的有效 MIS 成交快照，明確標成「局部」。不以委買／委賣填補成交點，沒有資料不畫假直線。過久未更新的分時線會用虛線，完整來源與時間可在列提示查看。

本機快照逐分鐘彙整、約每分鐘保存，與來源分鐘線分開快取，每檔只顯示當天資料。純數字模式不自動請求 Yahoo 分時資料；沒有新增交易或下單功能。盤中長時間連續更新仍需實盤驗證。

## 示範模式

執行 `smallstocks-tw.exe --demo` 使用持續變動的合成行情，畫面明確標示。設定與歷史預設使用獨立資料夾；若要建立提醒驗證通知，可將更新間隔設 5 秒，針對 2330 設定上下約 2% 波動範圍內的價格門檻。

程式採單一實例。切換一般／示範模式前，請先從系統匣結束目前程式，再開啟另一模式；單純隱藏視窗仍算執行中。

瀏覽器 `npm run dev` 只提供合成 UI 預覽，不會真的抓行情、持續判定或提供 MCP。完整示範請執行桌面版 `--demo`。

## Agent / MCP（選配）

先開啟桌面程式，然後在支援本機 stdio MCP 的 agent 裡加入：

```json
{
  "mcpServers": {
    "smallstocks-tw": {
      "command": "P:\\完整路徑\\smallstocks-tw.exe",
      "args": ["--mcp"]
    }
  }
}
```

連接示範實例時 args 改為 `["--mcp", "--demo"]`。這個 stdio bridge 連到已啟動本體，不另啟行情輪詢。本體關閉時會回報無法連線。

工具：`get_status`、`get_daily_history`、`get_intraday_history`、`list_events`、`list_rules`、`set_watchlist`、`set_settings`、`upsert_rule`、`delete_rule`。桌面與 MCP 讀寫相同規則，寫入後立即生效。自然語言由使用者自己的 agent 轉成工具欄位，程式不內建 LLM 或模型金鑰。

`get_daily_history` 以 `symbol` 和 `month`（YYYY-MM）讀取每日歷史；第一次回應可能為 `pending=true`，等待背景取得後再讀。`get_status` 亦提供休市摘要 `dailySummaries`。Agent 應報告資料日期、來源及是否快取／示範，不能把收盤資料稱作即時報價。

`get_intraday_history` 以已加入自選的 `symbol` 取得當天分鐘線；第一次亦可能 `pending=true`。`get_status` 只回傳分時來源、點數及時間等摘要，需完整點位時才使用專門工具。`set_settings` 可設定 `rowDisplay: "numbers"`、`"trend"` 或 `"minimal"`，以及布林值 `showCodes`、`alwaysOnTop`（主視窗置頂）；盤中／休市的曲線類型由本體依時段決定。

例如：「幫我盯 2330，成交價向下跨過 1000 元，用灰階細條提醒，每天一次。」Agent 可先呼叫 `set_settings` 設 `appearance: "gray"`，再以 `upsert_rule` 建立：

```json
{"symbol":"2330","metric":"price","direction":"below","threshold":1000,"channel":"strip","repeat":"daily"}
```

規則由本體持續執行，agent 關閉仍有效。定時摘要則需 agent host 自己安排；建立監看規則不等於建立 agent 排程。`get_status` 的 `demo`、`error`、來源時間也應一起納入報告。Agent 若使用雲端模型，讀出的內容可能傳給該模型服務。

本機 bridge 使用隨機 loopback 連接埠與 bearer token，不提供外網監看服務。連接資料存於應用程式資料夾，勿分享 `mcp-connection.json`。

## 開發與驗證

需要 Node.js 24、Rust stable 與 Windows C++ 建置工具。

```powershell
npm install
npm run tauri dev
npm run tauri dev -- -- --demo
npm run build
npm test
cargo test --manifest-path src-tauri/Cargo.toml --lib
npm run tauri build
```

UI 檢查：先執行 `npm run dev`，再 `node scripts/ui-check.mjs`（使用本機 Edge 與 Playwright）。

完整桌面整合檢查：完成 release 建置並結束其他實例後執行 `npm run check:desktop`。收盤後真實接入檢查可執行 `node scripts/live-check.mjs`。兩者均使用獨立測試資料夾並在結束後關閉測試程式。驗證紀錄見 `docs/IMPLEMENTATION_REPORT.md`。

資料預設存於 `%APPDATA%\SmallStocks-TW`，示範為 `%APPDATA%\SmallStocks-TW-demo`。測試可設定 `SMALLSTOCKS_CONFIG_DIR` 為獨立資料夾，桌面與 bridge 必須使用相同設定。

指定獨立測試資料夾時，程式會為該路徑使用獨立的實例鎖，讓測試不會喚起或操作正在使用的正式實例。
