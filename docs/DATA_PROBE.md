## 0.1.1 每日歷史探查

2026-11-06 收盤後核對下列官方端點與實際 JSON 欄位，未保存整包原始資料：

- TWSE `exchangeReport/STOCK_DAY`：按 stockNo、date（YYYYMM01）讀月份。fields 含日期、成交股數、開高低收與漲跌價差，日期是民國年。
- TWSE `indicesReport/MI_5MINS_HIST`：加權指數按月開高低收，無成交量及直接漲跌欄；同月相鄰收盤可計算差額，月初缺前日參考時保留空值。
- TPEx `www/zh-tw/afterTrading/tradingStock`：code、date（YYYY/MM/01），資料在 tables[0]。本輪欄位為「成交張數」與「成交仟元」，不得當成 TWSE 的股數。日期是民國年。
- TPEx `www/zh-tw/indexInfo/inx`：官方櫃買指數歷史頁 inline tables 設定所指定的 action。按月資料為西元日期、開市、最高、最低、收市與漲/跌，無成交量。已實際讀取 2026-10。

以欄位名稱對應解析，未知格式回報錯誤，不自行猜測固定位置。價格缺值與未能比價的漲跌欄保留缺值，不借用其他日期的即時百分比補值。價格未還原。

## 0.1.4 單行當日線

依使用者選擇接入當天分鐘線。2026-11-06 收盤後，Yahoo Finance `v8/finance/chart/{symbol}?range=1d&interval=1m` 對 2330.TW、0050.TW、6488.TWO、^TWII 均實際回傳 271 個時間點，範圍為當日 09:00–13:30。`meta.dataGranularity=1m`、symbol 與資料日期均驗證後才採用，null 保留為斷點。

^TWOII 查詢回傳 404，不能冒充可用櫃買資料；MIS getChartOhlcStatis 在此輪亦逾時。因此櫃買指數及來源無法補齊時，只能明確顯示本機 MIS 成交觀測的局部線；不足兩點則等待，不畫直線充數。

來源沒有提供可依賴的延遲保證。本體標示「分鐘線可能延遲」，數字與事件仍依原 MIS 來源，兩種來源不拼接、不互相補值。官方 Yahoo 對資料延遲的說明：[Exchanges and data providers](https://help.yahoo.com/kb/finance/article-exchanges-data-delays-sln2310.html)。公開可讀端點不是穩定服務或資料授權的保證；既有資料使用條件待確認事項仍保留。

目前只驗證收盤後實際補線，盤中連續更新的延遲與穩定性尚待交易時段測量。
